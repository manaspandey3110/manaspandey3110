### 💼 Featured Projects

#### 🏙️ CivicPulse — Civic Complaint Management Platform
`Node.js` `Express.js` `MongoDB` `JWT` `AWS (EC2, S3)` — *Nov 2025*

- Built an 18-endpoint REST API with role-based access control for citizen, admin, and department users, secured through custom JWT authentication/authorization middleware
- Modeled Users and Complaints with Mongoose; used bcrypt password hashing and a GeoJSON `2dsphere` index for database-level "nearby complaints" geospatial queries
- Handled multipart image uploads via Multer + Cloudinary, with automatic department routing based on complaint category
- Enforced one-vote-per-user upvoting and role-scoped data access, keeping each user role's permissions isolated
- Deployed and hosted on AWS EC2 with S3 for secure media storage

#### 🚚 Smart Delivery Route Optimizer
`C++11` `Node.js` `Express.js` `MongoDB` `OSRM` `Nominatim` — *Jul 2025*

- Built a Node.js/Express REST API with JWT auth and bcrypt hashing, backed by Mongoose models for Users, Locations, and Routes
- Integrated Nominatim geocoding (rate-limited, with Open-Meteo fallback) and the OSRM driving-route API for real road-network distance and route geometry
- Designed a standalone **C++11 Dijkstra's shortest-path engine** using an adjacency-list graph and priority queue, built separately from the API to demonstrate core graph-algorithm/DSA skills
- Persisted per-user route history, exposing an endpoint that returns each user's 50 most recent routes
- Deployed on AWS EC2 behind an Elastic Load Balancer
